# Customer Shopping Behaviour Analysis

**End-to-End Data Analytics Project**

## Project Overview
Analysed 3,900 retail transactions to understand customer purchasing patterns, spending behaviour, product preferences and subscription trends.

## Tools & Technologies
- Python (Pandas, NumPy)
- Jupyter Notebook
- PostgreSQL
- SQL
- Power BI

## Project Workflow
1. Data Cleaning and Preprocessing using Python.
2. Database Storage using PostgreSQL.
3. Business Analysis using SQL.
4. Interactive Dashboard Creation using Power BI.

## Key Insights
- Total Revenue: Approximately $233K.
- Average Order Value: $59.76.
- Average Product Rating: 3.75/5.
- Subscription Rate: 27%.
- Clothing contributed approximately 45% of revenue.
